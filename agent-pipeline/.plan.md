# 方案：agent-pipeline 项目管理功能

## 目标

在左侧增加"新建项目"+ "项目列表"（参考 sf-portal-mvp 的 SessionNav 样式），进入页面时右侧不展示流水线卡片（显示提示），新建/选择项目后展示卡片，点击卡片跳转时 URL 带 `?projectname=xxx`。

## 布局变化

```
┌─────────────────────────────────────────────────────┐
│ TopBar (36px)                                       │
├──────┬──────────────┬───────────────────────────────┤
│ Left │ ProjectNav   │ portal-content                │
│ Tool │ (新建项目     │                               │
│ bar  │  + 项目列表)  │ EmptyState 或 AgentsPanel     │
│ 56px │ ~260px       │                               │
└──────┴──────────────┴───────────────────────────────┘
```

- LeftToolbar（56px）不变
- 新增 ProjectNav（~260px，左侧第二列）：顶部"新建项目"按钮 + 下方可滚动项目列表
- portal-content（右侧）：无项目时显示 EmptyState（"请新建项目或选择已有项目"），有项目时显示 AgentsPanel

## 项目数据模型

```js
{
  id: "proj_<timestamp>",
  name: "项目 07-08 18:30",        // 显示名（时间戳）
  projectname: "4k6u",              // 随机 4 位字母数字，用于 ?projectname=xxx
  createdAt: 1720065000000,         // 创建时间
}
```

- 存储：`localStorage`（key: `agent-pipeline-projects`），纯前端，不改后端
- `projectname` 生成规则：4 位 `[a-z0-9]` 随机字符串（如 `4k6u`、`qx2v`）

## 修改文件

### 3. `src/App.jsx`（核心改动）

```jsx
function App() {
  const [projects, setProjects] = useState(() => loadProjects())  // localStorage
  const [selectedProject, setSelectedProject] = useState(null)    // 选中的项目对象

  // 新建项目：生成随机 projectname + 存 localStorage + 选中
  const handleNewProject = () => {
    const proj = {
      id: `proj_${Date.now()}`,
      name: `项目 ${formatTime(Date.now())}`,
      projectname: randomCode(4),   // 如 "4k6u"
      createdAt: Date.now(),
    }
    setProjects(prev => [proj, ...prev])
    setSelectedProject(proj)
    saveProjects([proj, ...projects])
    // 更新当前 URL
    window.history.replaceState(null, '', `?projectname=${proj.projectname}`)
  }

  // 选择历史项目
  const handleSelectProject = (proj) => {
    setSelectedProject(proj)
    window.history.replaceState(null, '', `?projectname=${proj.projectname}`)
  }

  return (
    <main className="portal-shell">
      <TopBar />
      <LeftToolbar />
      <div className="portal-content">
        <ProjectNav
          projects={projects}
          selectedId={selectedProject?.id}
          onNewProject={handleNewProject}
          onSelectProject={handleSelectProject}
        />
        <div className="portal-main">
          {selectedProject
            ? <AgentsPanel userInput={userInput} projectname={selectedProject.projectname} />
            : <EmptyState />
          }
        </div>
      </div>
      <ChatDialog ... />
    </main>
  )
}
```

### 4. `src/components/AgentsPanel.jsx`（卡片跳转带 projectname）

- `AgentsPanel` 接收 `projectname` prop，传给 `AgentNode`
- `AgentNode.handleClick`：跳转 URL 追加 `?projectname=xxx`

```jsx
function handleClick() {
  if (!clickable) return
  if (st === 'pending') onActivate(id)
  // 在 agent URL 后追加 ?projectname=xxx
  const separator = url.includes('?') ? '&' : '?'
  window.open(url + separator + 'projectname=' + projectname, '_blank', 'noopener')
}
```
