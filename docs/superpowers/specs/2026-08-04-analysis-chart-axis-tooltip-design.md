# 综合分析弹窗图表轴标题与悬浮提示设计

## 背景与目标

右侧栏第一栏展开的综合分析弹窗包含四张 AIS 图表：速度变化、速度与国土距离、航向分布、活动时段。本次调整统一四张图的纵轴标题、优化弹窗内布局，并让用户通过鼠标悬浮读取对应纵轴值。

## 范围

- 保留现有四张图及其数据来源、统计摘要和颜色语义。
- 将“速度（节）”“点位数”“报点数”按“距离（海里）”的样式竖向显示。
- 优化四图在弹窗内的尺寸、留白、对齐和响应式排列。
- 折线图按鼠标位置选择最近数据点，柱状图按悬浮柱选择对应值。
- 悬浮提示只显示纵轴值，不显示日期、时段、方向等横轴信息。
- 不引入第三方图表库，不修改分析数据计算或弹窗其他业务内容。

## 设计

### 图表布局

桌面弹窗使用统一的两列两行网格。四张卡片采用一致的图表高度、坐标轴边距、标题区和统计区间距，使同行卡片对齐。窄屏时沿用单列响应式布局，避免坐标轴或标签横向溢出。

纵轴标题使用同一个 SVG 文本样式和旋转方式，标题与刻度分别占用固定留白。双纵轴图左侧显示“速度（节）”，右侧显示“距离（海里）”；其余图仅显示左侧纵轴标题。

### 折线悬浮交互

每条可交互折线增加透明的宽描边命中层，视觉折线保持原样。鼠标在命中层内移动时，根据指针横坐标选择该序列最近的数据点，并显示定位在图内的自定义 tooltip。

速度变化图的 tooltip 只显示速度值和单位，例如“8.6 节”。双折线图分别为速度线和距离线建立命中层；鼠标悬浮在哪条线附近，就只显示该序列最近点的纵轴值，例如“8.6 节”或“24 海里”。不显示日期或其他横轴数据。

鼠标离开图表或命中区域时关闭 tooltip。当前点可使用小圆点高亮，帮助用户确认数值对应位置，但不增加额外文字。

### 柱状图悬浮交互

整根柱体作为命中区域。鼠标进入柱体时显示该柱的纵轴数值，航向分布与活动时段都只显示整数，不附带横轴分类。鼠标离开时关闭 tooltip。

### 组件边界

在 `AnalysisPanel.jsx` 内增加可复用的 SVG tooltip 渲染与定位逻辑，由折线图和柱状图共同使用。各图仍负责自己的数据范围、坐标换算和单位格式化；tooltip 只接收已格式化的纵轴文本及锚点坐标。

现有工作区中与分析面板相关的未提交改动全部保留，本次实现只在四张图、相关样式和测试范围内增量修改。

## 边界情况

- 数据不足时继续显示现有空状态，不渲染交互层。
- 空值数据点不参与最近点选择。
- tooltip 靠近图表左右或顶部边界时调整锚点，避免超出 SVG 可视区域。
- 柱值为零但图表仍有其他有效数据时，零值柱保留最小可命中高度并显示 `0`。
- 触摸设备不依赖 hover；现有图表内容保持可读，不因缺少 tooltip 影响核心信息。

## 验证

- 静态渲染测试确认四张图数量、四个纵轴标题及 tooltip 命中结构存在。
- 单元测试覆盖最近数据点选择、只显示纵轴值以及空值过滤。
- 运行项目测试与生产构建。
- 在浏览器中打开右侧栏综合分析弹窗，检查桌面两列布局、窄屏单列布局、双折线分别命中、柱体悬浮，以及 tooltip 不越界。
