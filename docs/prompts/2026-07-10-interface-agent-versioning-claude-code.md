## 目标

为 `interface-agent` 实现完整的界面稿版本机制：每次成功生成形成不可变版本；用户可以切换任意版本，并基于所选版本及其祖先上下文继续修改；历史版本修改形成分支；版本历史可持久化、恢复、分享、确认和交付。

## 架构边界

- 版本机制由 `interface-agent` 独立拥有。
- 不得把版本数据、会话或 API 接入 `factory-server`，也不要修改 `factory-server`。
- `interface-agent` 第一阶段按单实例运行：SQLite 保存元数据，Blade OS 保存不可变版本 HTML。
- SQLite 必须位于容器持久卷；替换容器后数据仍存在。
- `agent-pipeline` 只允许做项目入口和编辑凭证传递所需的最小改动。
- `projectname` 只用于项目定位和文件路径，不能作为授权凭证。

## 必须实现的行为

### 会话与版本

- 同一 `projectname` 默认恢复当前活跃的界面设计会话。
- 没有 `projectname` 时创建独立会话，并提供可恢复的会话入口。
- 默认模板不算版本；第一次成功生成或显式导入旧稿后创建根版本 `V1`。
- 正常主线生成 `V1 -> V2 -> V3`。
- 从历史版本分叉生成 `V1.1`、`V1.2`；从 `V1.1` 继续生成 `V1.1.1`。
- 真实关系只能使用不可变 `versionId` 和 `parentVersionId`，不能解析显示版本号推断父子关系。
- 版本 HTML 和编号不可修改；版本标题可以编辑且不创建新版本。
- 单版本不支持硬删除；支持分支归档/恢复。重新开始时归档当前会话并创建新会话。

### 异步生成

- 把同步生成流程改造成可恢复的异步生成记录，状态至少包含 `queued / generating / saving / succeeded / failed`。
- 创建请求立即返回 `202` 和 `generationRequestId`；前端可轮询或使用现有技术栈适合的事件机制恢复进度。
- 每个请求使用幂等键。刷新、超时或重复提交不得重复调用模型或创建版本。
- 模型上下文只包含所选 `baseVersionId` 的 HTML、祖先版本指令和本轮新指令；不得包含兄弟或后代分支指令。
- 只有模型生成、HTML 校验和 Blade OS 文件写入都成功后，才在 SQLite 事务内原子分配编号并创建版本。
- 失败请求保留执行记录，但不占用版本号、不进入版本树。
- 并发基于同一主线头生成时，只允许先提交成功者推进主线，后提交者成为原基线分支。

### 分享、确认与交付

- 分享、确认采用、下游交付必须是三个独立操作。
- 分享链接使用独立、不可猜测、可撤销、可过期的只读令牌，并永久固定到分享时的版本。
- 确认采用使用 `expectedConfirmedVersionId` 做乐观并发控制；冲突返回 `409`，不得静默覆盖。
- 当前选中版本属于用户个人界面状态；已确认版本属于会话共享状态。
- 确认成功后创建独立交付记录。Blade OS 输出或流水线通知失败不能撤销确认，应显示可重试状态。
- 新确认版本必须使旧的未完成交付变为 `superseded`；交付重试必须幂等，不能重复推进流水线。
- 保持现有 `<base>/<projectname>/prototype.html` 下游兼容输出。

### 前端

- 在预览区工具栏增加当前版本控件，点击打开版本树弹层。
- 树节点显示版本号、标题、创建时间、指令摘要和已确认标记。
- 切换版本立即更新预览和后续生成基线，不改变已确认版本。
- 新版本成功后自动选中并定位。
- 聊天区默认展示当前分支上下文，并提供“全部操作记录”视图。
- 输入区持续显示当前基线版本。
- 分享和确认采用使用独立按钮。
- 用“重新开始”替代覆盖式重置，并提供明确确认。
- 版本树支持归档显示开关；第一阶段不实现自动 diff。
- 保持当前视觉体系和响应式行为，不做无关页面重构。

### 访问控制与迁移

- 每个界面设计会话使用高强度编辑凭证，数据库只保存哈希。
- 长期编辑令牌不得持续暴露在查询参数、日志或 Referer；实现一次性启动码换取 HttpOnly Cookie，或提供同等安全且有测试的方案。
- 对所有版本写操作校验会话归属，禁止跨会话引用父版本、基线版本或确认版本。
- `agent-pipeline` 为项目保存并传递所需凭证；已有项目必须有兼容迁移路径。
- 检测旧 `interface-agent-state` 中的非默认 HTML，首次进入无版本项目时允许用户显式导入为 `V1`。
- 旧稿只能迁移一次；默认模板和空内容不迁移。
