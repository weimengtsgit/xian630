# 智能应用商店 (Smart App Store)

作战管理中心 — 情报分析人员使用的卡片式智能软件目录。

## 功能概览

- **卡片式网格布局** — 以卡片形式展示内置智能应用，含图标、名称、描述、分类标签
- **新品推荐区域** — 顶部高亮展示最新上架的应用，视觉与普通卡片区分
- **分类筛选** — 按态势监测、情报分析、活动规律、智能助手分类浏览
- **收藏切换** — 每张卡片支持收藏/取消收藏状态切换（含动画反馈）
- **详情面板** — 点击卡片弹出模态详情，展示完整描述、功能特性、应用信息
- **访问跳转** — 详情面板提供"访问应用"按钮，跳转至对应应用链接
