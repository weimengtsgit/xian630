# 航母母港潮汐出港窗口监测看板-BV5P

面向母港出港调度/指挥人员的 2×2 四格航母母港潮汐出港窗口监测看板。运行时接入公开潮汐预测 API，获取诺福克、圣迭戈、布雷默顿、横须贺四大航母母港未来 72 小时潮汐序列，按 **12.8 米吃水阈值**（换算至与潮高同基准）计算各港连续可出港时间窗；窗口开放显示绿色、关闭显示红色倒计时；每 10 分钟自动刷新。

## 数据源与诚实数据声明（live_api）

本应用为 **live_api 真实数据模式**，全部潮汐数据在运行时（浏览器端）从免鉴权官方公开接口获取，**不含任何 mock / 演示 / 合成数据**：

| 港口 | 数据源 | 基准 | 说明 |
|---|---|---|---|
| 诺福克 | [NOAA CO-OPS](https://tidesandcurrents.noaa.gov/stations.html) 站 8638610 | MLLW | 逐时预测，免鉴权 |
| 圣迭戈 | NOAA CO-OPS 站 9410170 | MLLW | 同上 |
| 布雷默顿 | NOAA CO-OPS 站 9447130（普吉特湾/西雅图） | MLLW | 布雷默顿本站 9446486 不发布 MLLW 逐时预测，采用邻近普吉特湾预测站 |
| 横须贺 | [JCG 日本海上保安厅潮汐推算](https://www1.kaiho.mlit.go.jp/TIDE/pred2/) area=1407 | 平均海面 | 毎時潮高表（cm）解析换算为 m，当日起 4 个日页拼合 72h |

浏览器 JS **不直连外部域**：全部请求走本站 nginx 同源反向代理（`/api/noaa/`、`/api/jcg/`），规避 CORS 并统一出口。

## 判定口径（阈值换算）

各港潮高基准不同（MLLW / 平均海面），12.8 米吃水阈值不能直接与潮高比较，须先换算：

```
潮高判定阈值（米，与该港潮高同基准） = 12.8 − 泊位基准水深（米）
```

| 港口 | 泊位基准水深（缺省值） | 潮高判定阈值 |
|---|---|---|
| 诺福克 | 12.2 m | 0.60 m（MLLW） |
| 圣迭戈 | 12.0 m | 0.80 m（MLLW） |
| 布雷默顿 | 12.2 m | 0.60 m（MLLW） |
| 横须贺 | 11.9 m | 0.90 m（平均海面） |

- 泊位基准水深为**公开资料整理缺省值（待官方海图校准）**，集中在 `src/config/ports.js`，校准只需修改该文件。
- 窗口判定：潮高连续 ≥ 判定阈值的时段合并为可出港时间窗，窗口边界由相邻整点线性插值解出；未来 72 小时内无满足时段时显示「无可用窗口」空态，不虚构窗口。

## 状态语义（颜色 + 图标 + 文字三重信号）

| 状态 | 含义 |
|---|---|
| 🟢 窗口开放 | 当前潮高 ≥ 判定阈值，倒计时至窗口关闭 |
| 🔴 窗口关闭 | 潮高低于阈值，倒计时至下一窗口开启 |
| ⚠ 取数失败 | 该港取数失败，仅该格显式报错（错误码 + 时间 + 手动重试） |
| ◆ 数据陈旧 | 超 10 分钟未成功刷新，保留最后成功值并打陈旧标记 |
| ○ 无可用窗口 | 72 小时内潮高均未达阈值 |
| ⟳ 加载中 | 首次取数骨架屏，不预填任何示意值 |

四港数据链路完全独立，单港失败不影响其他港口。

## 刷新与时区

- 每 10 分钟自动刷新 + 手动刷新；倒计时由本地时钟每秒插值，取数失败不重置。
- 窗口起止与潮高时间轴为**港口当地时间**（美东/美西/日本）；刷新时间统一**北京时间**。

## 已知限制与复核事项

1. 生成环境出口网络无法访问 NOAA 域与 JCG 数据明细页（数据接入阶段与生成阶段实测一致），适配器按 tide-data-skill 已验证契约实现，**上线后需真机复核四港真实响应与 JCG 毎時潮高表结构**。
2. JCG 推算页结构变化时横须贺格将显式报错（`JCG_PARSE_FAILED` / `JCG_CGI_INPUT_ERROR`），不伪造数据。
3. 泊位基准水深缺省值待用户校准（见上表）。

## 本地开发与构建

```bash
npm install     # 工厂不提供 package-lock.json，必须用 npm install
npm run dev     # 开发服务器（vite.config.js 已含与 nginx 同构的本地代理）
npm run build   # 产出 dist/，完全离线，无任何构建期取数
```

## 容器构建与部署（Podman/Docker）

```bash
podman build -t command-dashboard-bv5p .
podman run -d -p 8080:80 command-dashboard-bv5p
```

运行时容器需要能访问 `api.tidesandcurrents.noaa.gov` 与 `www1.kaiho.mlit.go.jp`（由 nginx 出口代理）；不可达时应用呈现按港独立的显式降级态。
