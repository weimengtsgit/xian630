### description

本项目面向海上态势值守监控人员与情报分析人员，目标是构建一个全球海域舰船目击社媒监控应用（command_dashboard 类型），用于从社媒公开帖文中及早发现疑似舰船（尤其是航母）经过引发的目击潮。范围限定为全球海域：以多语言关键词（航母、军舰、大船、海上等）检索 X（推特）与 Instagram 公开帖文，提取帖子 GPS 标签或图片 EXIF 中的经纬度坐标，将带坐标帖子在全球地图上以散点落点展示，并对同一海域短时间内多个不同账号发布相似内容的情况自动聚合并高亮为目击潮聚类事件、在告警栏给出提示。关键能力包括：每 15 分钟定时增量抓取节奏（当前由显著标注的演示数据驱动轮询模拟）、GPS 标签与图片 EXIF 双通道坐标提取、多语言关键词全球海域检索、同海域短时多账号相似发帖的自动聚合与高亮、全球地图散点落点展示与新帖流告警栏，以及预留的真实接口接入切换层。真实平台接口对接、真实图片 EXIF 解析与真实定时抓取流量不在本次生成范围内，仅在架构上预留。蓝图 social-sighting-cluster-alert 仅作为参考场景文档，不直接复用其实现。

### risks

- 真实平台接口不可直接使用：X（推特）与 Instagram 搜索接口受授权、付费与频控限制，真实接入层仅做预留，后续切换时需补充鉴权、限流与合规设计。
- 真实场景下帖子坐标覆盖率低：多数社媒帖文不含 GPS 标签且图片 EXIF 常被平台剥离，真实数据源接入后散点密度与目击潮检出率可能远低于演示数据效果。
- 目击潮聚类存在误报与漏报风险：同海域短时多账号相似发帖的判定阈值设置不当，可能将普通热门话题误判为舰船目击潮或遗漏真实目击潮，阈值需可调并支持人工复核。
- 演示数据契约与真实接口结构偏差风险：若演示数据字段结构与未来真实接口返回不一致，真实切换成本将显著增加，需在数据接入阶段严格对齐实体模型。
- 多语言关键词召回偏差：不同语言的关键词覆盖不全或翻译不地道，可能导致部分海域、部分语种的目击信息被遗漏。
