# 全球海域舰船目击社媒监控-IF2L

面向海上态势值守监控人员与情报分析人员的指挥监控大屏（command_dashboard）：
以多语言关键词（航母 / 军舰 / 大船 / 海上等语义等价词，覆盖 zh / en / ru / ja / es / ar 六语种）
每 15 分钟轮询 X（推特）与 Instagram 公开帖文（**演示数据驱动**），提取 GPS 标签与图片 EXIF
双通道经纬度，在全球海域地图形成帖子落点散点图；当同一海域短时间内多个不同账号发布相似
内容时，自动聚合高亮为「目击潮」聚类事件并告警，提示疑似舰船（尤其是航母）经过。

## ⚠️ 数据口径声明（必读）

- 本应用数据口径为 **mock_data（演示数据）**：全部帖子、账号、坐标、聚类事件与批次统计
  均由本地确定性生成器合成（种子 PRNG，可复现），**不含任何真实平台数据**。
- 运行时**零外网请求**：不对 X（推特）/ Instagram 发起任何自动化抓取；演示加速开关仅缩短
  本地定时器的真实等待间隔，不产生真实流量。
- 界面在顶栏徽标、地图水印、帖子卡片、批次与统计面板等多处**显著标注「演示数据」**。
- 真实图片 EXIF 解码不在本次范围：双通道坐标为数据集内置模拟提取结果。
- 真实平台接口经数据接入阶段探测证实**无免鉴权公开搜索通道**（X API v2 recent search 返回
  401 需付费层 Bearer Token；Instagram Graph API 返回 OAuthException #200 需 Meta App +
  IG Business 鉴权；两平台网页端均为登录墙 + JS 渲染）。live 通道仅按预留规格固化。

## 功能结构（首页 7 分区）

| 分区 | 说明 |
|---|---|
| 顶部指挥状态栏 | 应用标识、数据源状态灯（X / Instagram / 坐标双通道）、demo/live 模式切换（live 为禁用预留）、上次抓取与下次抓取倒计时（15 分钟节奏）、系统时钟、演示徽标、演示加速 ×60 开关 |
| 目击潮告警条 | 最新聚类事件滚动播报（紧急红 / 关注黄 / 正常绿隐藏），支持地图定位与进入复核；失败批次提示重试 |
| 监控任务与筛选面板 | 多语言关键词组启停与新增、平台开关、坐标来源（GPS 标签 / 图片 EXIF）筛选、时间窗（1h / 6h / 24h）、聚类阈值配置入口 |
| 全球海域态势地图（主视图） | 本地示意底图 + 海区网格（12 个主要海域）、帖子落点散点（平台着色 / EXIF 空心）、目击潮聚类高亮圈（脉冲）、热度层、缩放平移、点选下钻、空态引导 |
| 新帖流 | 按抓取批次增量分组的帖子卡片（账号 / 平台 / 语言 / 命中词 / 坐标徽标 / 时间 / 摘要），支持定位与标记误报；无坐标帖子保留展示但不落点 |
| 目击潮聚类事件列表 | 事件卡片（海域 / 时间窗 / 账号数 / 帖子数 / 半径 / 相似度 / 复核状态），选中下钻：成员帖子对照、发帖节奏、疑似目标类型、确认 / 排除复核、导出值班纪要（演示） |
| 抓取轮询时间线 + 坐标双通道统计 | 15 分钟批次轴（新帖量 / 带坐标量双色柱）、批次点击回看、失败批次重试（演示）；GPS 标签 / EXIF 双通道占比统计 |

## 交互状态

`default` 正常值守 · `cluster_alert` 目击潮告警（告警条滚动 + 地图聚类圈脉冲）·
`loading` 抓取中（顶栏批次进度 + 时间线进行态 + 地图扫描线）· `empty` 空态（筛选引导 + 回显）·
`error` 数据源异常（源灯红 + 失败批次标红 + 重试）· `stale` 数据过期（超过一个轮询周期未成功更新，顶栏转黄）。

说明：stale 为诚实触发（如会话挂起超过 15 分钟），不做人工模拟。

## 目击潮聚类判定（阈值可配置）

- 判定要素：同海域 + 时间窗内 + 半径内 + 不同账号数 + 内容相似度（CJK 按字、其他按词的
  Jaccard 相似度：0.7 × 文本 + 0.3 × 命中词）。
- 默认阈值：时间窗 60 分钟 / 海域半径 50 km / 最少不同账号 3 / 最低相似度 0.6，
  可在「聚类阈值配置」弹窗调整并即时重算。
- 严重度：紧急 = 账号 ≥6 或（账号 ≥4 且相似度 ≥0.88）；关注 = 账号 ≥4 或相似度 ≥0.75；其余正常。
- 复核状态：待复核 / 已确认 / 已排除，人工流转；同账号多发帖不满足账号数阈值，不触发聚类。
- 演示剧本：西太平洋 6 账号目击潮（紧急 · 待复核）、阿拉伯海 4 账号（已确认）、
  南大西洋 5 账号（已排除）、南海同账号多发边界样本（不聚类）、1 个失败批次（可重试）。

## 数据接入架构（demo / live 可切换）

```
DataSourceAdapter（统一契约：fetchBatch → { batch, posts }，前端只消费标准契约）
├── DemoDataSource       本次默认：本地确定性演示数据（近 24h · 96 批次 · ≥200 帖）
├── XSearchAdapter       live 预留：X API v2 recent search（付费层 Bearer Token，未启用）
└── InstagramGraphAdapter live 预留：ig_hashtag_search + top/recent_media（Meta App + IG Business，未启用）
```

- live 入口在顶栏为禁用预留态，点击给出诚实提示；适配器在未配置凭证时直接抛错，
  绝不发起网络请求，也绝不以演示数据伪装真实数据。
- 切换真实源时需经服务端网关（nginx 反向代理 + 鉴权注入 + 限流合规），浏览器一律走同源
  `/api/` 路径；本应用 nginx.conf 已留说明注释。
- 五实体契约（post / cluster / batch / keywordTask / system）与设计阶段 assumedDataFields
  一一对齐，切换数据源不重写前端。

## 运行

```bash
npm install
npm run dev      # 开发：http://localhost:5173
npm run build    # 构建：dist/（纯静态，无后端依赖）
```

容器（Podman/Docker）：

```bash
podman build -t command-dashboard-if2l .
podman run -p 8080:80 command-dashboard-if2l
```

- Dockerfile 使用 `COPY package.json` + `npm install`（不依赖 lockfile）。
- nginx 仅托管静态资源，SPA 回退到 index.html，运行时零外网请求。

## 演示提示

- 打开「演示加速 ×60」后，15 分钟轮询节奏以 15 秒真实间隔模拟，可观察批次推进、
  新帖流入与新增目击潮告警（每 9 个批次出现一波新的多账号相似发帖剧本）。
- 地图为本地打包的简化示意世界轮廓（等距圆柱投影，非精确地理渲染），海区为 12 个内置
  主要海域格网；真实接入后散点密度与聚类检出率将显著低于演示效果。
