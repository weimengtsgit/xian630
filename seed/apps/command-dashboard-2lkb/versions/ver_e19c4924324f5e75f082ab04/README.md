# 美航母海域商船密度网格告警-2LKB

面向情报分析人员的航母海域商船密度网格告警看板（指挥看板 / 深色作战风格）。

> **演示口径声明**：本应用全部数据为**预生成演示数据（mock）**，由种子化确定性生成器在浏览器内
> 模拟 AIS 商船密度数据流，**不接入、不代表任何真实 AIS 数据源**；网格中心坐标为演示值。
> 界面已在顶栏徽标与页脚全局标注。真实 AIS 接入需另行采购实时数据服务并重新进行数据接入确认。

## 业务规则（固定口径）

| 项 | 取值 |
|---|---|
| 监控网格 | 按美航母主要活动海域分组（西太平洋 / 南海 / 中东 / 地中海，演示配置），每海域 8 格（2×4），共 32 格，边长固定 **50 海里** |
| 刷新节奏 | 固定 **180 秒**（确定性游标推进），顶栏常显倒计时，支持立即刷新与暂停自动刷新 |
| 密度基线 | 同一网格**过去 30 天小时粒度滑动平均**（720 点，窗口随游标前移） |
| 告警分级 | `ratio = 当前在航商船数 / 基线`；`ratio < 0.50` → **净空告警（■ 红）**；`0.50 ≤ ratio < 0.70` → **净空预警（▲ 黄）**；其余 **正常（● 绿）**。阈值集中常量 `RATIO_RED_THRESHOLD / RATIO_YELLOW_THRESHOLD`，判定顺序先红后黄（唯一入口 `src/utils/alertRule.js`） |
| 状态语义 | 商船数量突然锐减即提示区域被净空（可能预示演习或攻击准备），辅助研判 |

## 页面结构（已确认原型，硬约束）

顶部状态栏 → 告警滚动条（红优先黄次之，点击定位网格）→ 指标总览条（随海域 Tab 联动）→
主体双栏（海域分组网格矩阵 + 右侧下钻详情栏）→ 状态反馈区 → 页脚演示口径声明。

- 每个方格：编号 + 当前在航商船数 + 当前/基线比率 + 近 24h 走势曲线（蓝色实线）+ 30 天基线（灰色虚线）+ 图标与中文状态徽标；曲线悬停有十字线与数值气泡。
- 下钻详情（必选组件）：30 天走势大图（10% 面积填充）、当前/基线/比率统计、70%/50% 阈值标尺与当前游标、网格元数据（边长 50 海里、中心坐标演示值）、状态时间线；红色告警格默认自动选中。
- 响应式：≥1440px 双栏（下钻栏约 340px，矩阵 4 列）；1024–1439px 双栏收窄（3 列）；768–1023px 单栏（2 列，下钻在选中格下方展开）；<768px 紧凑行卡（可展开曲线，顶栏精简两行）。
- 状态反馈：加载骨架屏、空态、错误态（演示数据流中断 + 重试，保留上次数据并标注时点）、数据滞后提示（超 180 秒，独立橙色，不占用黄/红告警色）。

## 数据架构（分层与审计边界）

```
src/
  constants.js            全局集中常量（阈值 / 180 秒 / 50 海里 / 演示声明）
  data/gridConfig.js      演示网格静态配置（4 海域 × 8 格）——数据层：仅静态定义与归一化，
                          无 Math.sin / Math.cos / Math.random
  utils/
    prng.js               种子化确定性 PRNG（mulberry32，不使用 Math.random）
    seriesGen.js          演示序列生成器（昼夜节律 + 种子噪声 + 预置锐减场景段）
    snapshot.js           派生计算：当前值 / 30 天基线 / 比率 / 分级 / 事件 / 聚合 / 数据流状态
    alertRule.js          告警分级唯一判定入口（先红后黄）
    format.js             展示格式化
  hooks/
    useDemoFeed.js        数据流模拟层：180 秒游标推进、立即刷新/暂停、中断段注入、stale 判定
  components/             UI 层（看板组件与 SVG 图表）
```

- 游标推进：`tick = floor((now − 锚点) / 180s)`，任意时刻全网取值一致、刷新可复现，不依赖随机数。
- 历史深度：每网格 30 天小时粒度（720 点）支撑滑动平均基线；近 24h 3 分钟粒度（480 点）驱动曲线。
- 锐减场景：预置 2 格红（WPAC-r2c3、MED-r1c2）、2 格黄（SCS-r1c4、WPAC-r1c2），跨 3 个海域，
  锐减段贴当前时刻（约 6.5 小时前开始、30 分钟内锐减到位），保证黄/红状态在验收演示中稳定可见。
- 中断演练：每 24 小时周期注入一次 6 分钟数据流中断段（约第 8 小时节点），用于验收错误态与重试链路。
- 本应用**不发起任何外部网络请求**（无 fetch / 无代理依赖），nginx 仅托管静态产物。

## 未来替换真实 AIS 适配器（本期不实现）

将 `src/utils/seriesGen.js` 的取值函数替换为真实适配器：AIS 位置报文（MMSI、经纬度、SOG/航态、
船舶类型）→ 按经纬度落入 50 海里网格 → 过滤商船类型与在航状态 → `currentCount`；
30 天逐 3 分钟序列滑动平均 → `baseline30d`。届时外部位标须经 nginx 反向代理接入，密钥不得进入前端。

## 构建与部署

```bash
npm install
npm run build     # 产物 dist/index.html
npm run dev       # 本地开发（默认 5173）
```

容器镜像（Podman/Docker）：镜像内 `npm install` + `vite build`，运行态 nginx:1.27-alpine 托管
静态产物（80 端口）。仓库不携带 `package-lock.json`，镜像构建使用 `npm install`（非 `npm ci`）。
