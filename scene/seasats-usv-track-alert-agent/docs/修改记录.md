## 2026-08-03 · 8 条新需求实现

### 需求1：左侧栏只展示无人艇
`src/app/VesselFocusPanel.jsx` 将 `isEscortVessel` 改为 export；`src/app/App.jsx` 在 `selectableTargets` 过滤里加 `!isEscortVessel(target.code)`。分类逻辑与右侧栏一致（属舰=DDG/CG/CVN/SSN/LHA/LHD/T-AO/T-AKE/T-AOE，其余为无人艇），航母与属舰不再出现在左侧栏。

### 需求2：AIS 开闭报警只展示近 1 周
`src/app/App.jsx` `displaySeedAnalysis` 过滤：`aisGaps` 只保留 `toTime` 在 7 天内；`alerts` 中 `type==="ais-gap"` 的只保留 `time` 在 7 天内，其他类型告警不过滤。`aisGapSinceMs = remoteMapEndTime*1000 - 7天`。

### 需求3：航向仅按 511（不可用标记）回退，不校验 0–360 范围
实际逻辑**只处理 511 这一种** AIS"不可用"标记，**不**判断角度是否落在 0–360 之内（如 456 这类越界脏值原样保留、不回退）。规则：`heading` 非 511 → 取 `heading`；`heading===511` → 回退 `orientation`；`orientation` 也为 511（或均缺失）→ `null`（显示 `--`）。由 `src/logic/heading.js` 的 `resolveHeadingValue(value)` 实现，`AlertCard.jsx`、`VesselFocusPanel.jsx`（`resolveDisplayedHeading`）改用它统一解析；服务端 `app-server.js` 的 `normalizePoint` 同样**不**做 0–360 过滤，仅在 `buildFastSummary`/`buildSummaryFromTracks` 独立透传 `orientation`/`heading` 字段，并将 `headingFieldVersion` 由 v1 升至 v2 以作废旧口径快照。

### 需求4：弹窗区块顺序 + 建议动作独占一行
`src/app/AnalysisPanel.jsx` 顺序改为：研判结论 → 关键证据 → 当前舰艇事件 → 建议动作 → AIS 轨迹图表。`src/styles/global.css` 加 `.analysis-group.advice-group { grid-column: 1 / -1; }`（独占整行）。

### 需求5：删除每日活动趋势图 + 折线图加纵坐标名称
`src/app/AnalysisPanel.jsx` 删除"每日活动趋势" `BarMiniChart` 及 days 计算（保留航向分布、活动时段柱状图）；`LineMiniChart` 新增 `yAxisLabel` 参数（速度变化传"速度（节）"）；`SpeedDistanceChart` 加左纵轴"速度（节）"、右纵轴"距离（海里）"旋转名称。CSS 加 `.chart-axis-label`。

### 需求6：关联历史展开箭头朝左
`src/app/VesselFocusPanel.jsx` `AffiliationSummaryRow` 的 `ChevronRight` 改为 `ChevronLeft`。

### 需求7：智能体研判只留研判结论句 + 移到关键证据上面
